# Security Policy & Privacy Guarantee

## 🛡️ Privacy Guarantee

**Offline Bible** is designed from the ground up as a **zero-telemetry, offline-first** application:

- **No User Tracking**: We do not collect, store, transmit, or monetize any personal data.
- **Local Storage**: All notes, highlights, bookmarks, reading history, and app preferences remain strictly on the user's local device (via encrypted Hive CE local boxes).
- **Network Transparency**: The app makes **no outbound network requests** during normal operation. The only network feature is the optional user-initiated download of additional public-domain scripture translations from `https://api.getbible.net`.
- **No Third-Party Analytics**: No ads, telemetry, trackers, or commercial advertising SDKs are bundled.

## 🚨 Reporting a Vulnerability

If you discover a security issue or vulnerability in Offline Bible, please **do not open a public GitHub issue**.

Instead, report the vulnerability responsibly by following these steps:

1. **Email Disclosure**: Send details to `security@genexis.dev` (or the repository maintainers).
2. **Include Details**:
   - Description of the vulnerability and attack vector.
   - Steps to reproduce or proof-of-concept code.
   - Affected device, platform (Android / iOS / macOS / Web), and app version.
3. **Response Timeline**:
   - Maintainers will acknowledge receipt within 48 hours.
   - We will provide an estimated timeline for remediation and coordinate a patched release.
4. **Responsible Disclosure**: Please allow sufficient time for a fix to be published before discussing the issue publicly.
